# 河湾议会

## 最小 Demo · 今晚，两户人家怎么过夜？

双击 `index.html` 即可试玩。白天，张家和李家各剩一次行动，现场有一户容量的仓房、干地、挂点和带系绳的防雨篷布。你可以制定新的入住制度，也可以用实际材料增加一个住处。

1. 写下办法并点击「审议办法」，也可以点「问 NPC 的办法」让 NPC 提案。
2. 如果经理需要更多信息，按问题答复，或者在它询问 NPC 时点「请 NPC 回答」。经理会带着前几轮答复继续核对同一份提案。
3. 看到草案后，核对实际占用的物资、能执行的家庭、产生的地点和容量。可以调整建造者与入住资格，然后确认启用。
4. 白天派人实际执行。入夜后为两户选择实际存在且有空位的住处，再点「结算今晚」。账本会记录澄清、采用的方案、实际行动和最终过夜地点。

启用方案会新增可用动作。只有实际搭建并占用资源后，地图上才出现新地点。游戏会再次核对权限、时间、行动次数与资源状态，再一起变更账本和地图。

## 模型设置

点「模型设置」，填写支持跨域访问的兼容模型接口。推荐在「MiniMax（浏览器直连）」中填写自己的密钥；密钥只在当前页面内存中有效。启用大模型后可自然语言声明有物资依据的组装办法，也可继续向 NPC 询问。离线可以通过「本地编译」试验出工后的入仓资格及是否可转赠。

独立盲测时，从空仓开局，让试玩者先说明自己想新增的动作、时段和结果，再看引擎实际发生了什么。场景中已有的属性、实际可用材料、干地和挂点决定可以实现的办法。

## 开发

使用 `npm ci` 和 `npm run build` 生成单文件 `index.html`，或用 `npm run check:build` 验证构建是否同步。

- `warehouse-engine.js` 定义场景事实、资源绑定、计划校验、动作及夜间结算。
- `warehouse-ui.js` 负责单屏场景、NPC 与经理的多轮澄清、草案和账本。
- `river-map.js` 绘制仓房和新地点的现场标记。
- `browser-model.js` 负责可选的浏览器模型连接。

在游戏地址后加 `#relief` 可进入七日安置版，加 `#seasons` 可进入八季经营版。
