# 河湾议会

《河湾议会》是一款八季的单城经营游戏。你从四名居民和一座河湾聚落起家，目标是在第二个冬季结束时建成至少三处设施，留下八份存粮，并保有四点民望。

## 游玩

双击 `index.html` 即可在浏览器打开游戏。在 Windows 上也可以双击 `Play.cmd`。单个 HTML 内包含界面、经营规则、地图和 Three.js，可以复制给别人离线游玩，也可以放到静态网站的目录里作为首页。

每季在地图上选地建设，给农业、林业和贸易分配人手，查看收支预估后结算。议事厅可提出当季周转或跨季履约的契约，是否采纳由玩家决定。每个季节结算后会自动存档。使用同一浏览器重新打开原地址或原文件可接着玩，具体取决于浏览器是否允许该页面使用本地存储。

## 大模型议会

默认使用离线的本地居民代表。要使用模型，点击齿轮或议事厅里的「配置大模型」，选择服务预设，填写完整请求地址、模型 ID 和所需的 API 密钥。点击「测试连接」可以试发一次请求，「保存并启用」后选择大模型代表即可征询。

浏览器直接请求你填写的接口。该接口必须允许页面来源发起跨域请求，支持相应的鉴权标头，并能用 Chat Completions 或 Messages 格式回复。直接打开 HTML 时，浏览器可能把它的来源标记为 `null`。游戏只在当前页面内存中保留密钥，重新打开或刷新页面后需重新输入。运行测试或征询议案时，密钥只发往你配置的接口。遇到连接失败或无效议案时，游戏会提示原因，并继续用本地代表生成提案。

## 开发

修改 `index.template.html`、`style.css` 或 JavaScript 源文件后，用 Node.js 运行：

```sh
npm ci
npm run build
```

产物为项目根目录的 `index.html`。使用 `npm run check:build` 检查它和源码是否同步。游玩直接使用生成的 HTML。

- `game-engine.js` 负责存档、经营结算、收支预估和本地议案。正式结算与预估共用同一套规则。
- `app.js` 负责浏览器交互，`river-map.js` 使用 Three.js 绘制地图。
- `browser-model.js` 处理可选的大模型接口。模型只从引擎允许的候选契约中推荐一份，并提供理由。
