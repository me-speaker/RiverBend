# 河湾议会

一款八季的单城经营游戏。你从四名居民和一座河湾聚落起家，目标是在第二个冬季结束前建成至少三处设施，留下八份存粮，并保有四点民望。

## 打开游戏

在装有 Python 3.10 或更高版本的 Windows 电脑上双击 `Play.cmd`，游戏会在默认浏览器里打开。也可以在本目录运行 `python server.py --open`，或用 `python server.py --port 8080` 指定端口后访问 `http://127.0.0.1:8080/`。

地图使用 Three.js 绘制 2.5D 卡通河湾，推荐使用支持 WebGL 2 的浏览器。Three.js r170 和授权文件随游戏存放在 `vendor/` 中，使用本地议会可全程离线游玩。游玩时请保持服务运行，关闭服务会清除本次游戏进度。

每季调整农业、林业和贸易的人手，在地图上选择要建设的地块，查看结算预估。议会是可选行动。你可以写下想优先解决的问题，征询一份议案，对照条款决定是否采纳，再结束本季。跨季契约会在到期时按库存结算。

## 使用模型议会

点击右上角齿轮，在「游戏设置」中配置大模型。议事厅里的「配置大模型」也会打开同一份表单。

1. 选择服务预设，填写完整的请求地址和服务端使用的模型 ID。
2. 按服务要求选择鉴权方式，填写 API Key。连接允许匿名访问的本机服务时，选择无鉴权。
3. 点击「测试连接」可以按当前填写的参数发送一次测试请求。点击「保存并启用」后，回到议事厅，确认选中「大模型代表」，再点「听取议案」。

征询时，服务会把游戏内的施政意图、城市摘要、用工计划和候选契约交给选定的模型。议案卡会标明实际来源。选择「本地规则代表」可以继续离线经营。

模型适配器和服务预设随游戏提供。浏览器设置保存在本游戏目录的 `.private/model.json`，也可手动填写。旧版原型用户若已在同级 `it-said-wed-win` 工程配置过模型，游戏会在本地配置缺失时沿用该配置。以下示例适用于本机 Chat Completions 兼容服务，模型 ID 应填写服务实际加载的名称。

```json
{
  "provider_id": "openai_compatible",
  "endpoint": "http://127.0.0.1:11434/v1/chat/completions",
  "model": "你的本机模型名称",
  "auth_type": "none",
  "output_mode": "json"
}
```

使用远程兼容服务时，请填写该服务提供的 HTTPS 接口地址，并按其要求配置鉴权方式和密钥。

## 一份议案怎样生效

`game.py` 给出当季候选契约及数值，`server.py` 用玩家当前的用工和建设计划逐份试算，筛出能执行的选项。`council.py` 把可选条款、预测和历史交给模型，由它选择提交哪一份，并说明居民的理由。玩家签署并推进回合后，游戏引擎扣付资源、登记欠款并结算履约。使用本地议会时，同一套结算规则支持对比试玩。
